# Инструкция по работе с технологией «Канарейка» через Canarytokens

> **Важно:** используйте данный подход только для законного и согласованного тестирования собственных каналов связи, ресурсов и процессов.

## Назначение

**Canarytokens** — это инструмент для создания специальных токенов («маячков»), которые отправляют уведомление при их активации.  
В рамках данной инструкции рассматривается тип токена **Web bug**, который позволяет отследить факт открытия ссылки и получить базовую техническую информацию о событии.

Такой подход может использоваться для:

- проверки канала связи на возможную утечку;
- контроля факта открытия переданной ссылки;
- тестирования внутренних процессов безопасности;
- фиксации времени и параметров срабатывания токена.

---

## Что потребуется

Перед началом работы подготовьте:

1. **Отдельный почтовый ящик** для получения уведомлений.
2. Доступ к сервису Canarytokens:
   - <https://canarytokens.org/nest/>
3. Понимание того, какой именно канал связи вы планируете проверить.

---

## Пошаговая инструкция

### 1. Создание почты

Создайте отдельный email-адрес, который будет использоваться только для получения уведомлений от Canarytokens.

**Рекомендации:**
- не использовать основной рабочий ящик;
- проверить, что входящие письма не попадают в папку «Спам»;
- сохранить учетные данные в безопасном месте.

---

### 2. Переход на сайт Canarytokens

Откройте в браузере страницу:

<https://canarytokens.org/nest/>

---

### 3. Выбор типа токена

В списке доступных вариантов выберите:

**Web bug**

Этот тип токена создает специальную ссылку, обращение к которой фиксируется сервисом.

---

### 4. Заполнение параметров

При создании токена укажите следующие данные:

#### Email для уведомлений
Введите адрес почты, на который будут приходить уведомления о срабатывании.

Пример:

`example.monitor@mail.com`

#### Текст сообщения / имя токена
Укажите понятное описание, чтобы можно было отличать один токен от другого.

Примеры:
- `Проверка канала связи 1`
- `Тестовая контрольная ссылка`
- `Проверка утечки - июль`

---

### 5. Генерация ссылки

После заполнения полей сервис сформирует уникальную ссылку.

Эта ссылка и будет являться вашим токеном для проверки канала связи.

---

### 6. Отправка ссылки в проверяемый канал

Сформированную ссылку необходимо отправить в тот канал связи, который вы хотите проверить.

**Варианты использования:**
- вставить ссылку в сообщение;
- включить в тестовую переписку;
- использовать в рамках контрольной отправки.

---

### 7. Ожидание уведомления

После отправки ссылки необходимо дождаться возможного срабатывания токена.

**Рекомендуемое время ожидания:** **7 дней**.

В течение этого периода следует отслеживать входящие письма на указанный email.

---

## Что приходит в уведомлении

При срабатывании токена на почту обычно приходит уведомление, содержащее:

- время события;
- IP-адрес источника;
- примерное местоположение;
- дополнительные технические данные.

Эта информация помогает понять:

- был ли совершен переход по ссылке;
- когда именно это произошло;
- откуда примерно пришел запрос.

---

## Интерпретация результатов

### Если уведомление пришло

Это означает, что ссылка была активирована.  
Следует проверить:

- соответствует ли время ожидаемому сценарию;
- известен ли IP-адрес;
- совпадает ли местоположение с предполагаемым;
- не указывает ли событие на возможную утечку.

### Если уведомление не пришло

Это может означать, что:

- ссылка не была открыта;
- сообщение не дошло до получателя;
- токен был заблокирован фильтрами;
- получатель не перешел по ссылке;
- период наблюдения оказался недостаточным.

---

## Практические рекомендации

### Используйте отдельный токен для каждого канала
Если проверяется несколько каналов связи, лучше создавать отдельный токен для каждого.

### Понятно называйте токены
Примеры:
- `Канал_A_июль`
- `Проверка_мессенджер`
- `Тест_почта_внутренняя`

### Ведите журнал проверок
Полезно фиксировать:
- дату создания токена;
- канал отправки;
- срок наблюдения;
- результат проверки.

### Проверяйте папку «Спам»
Иногда письма от сервиса могут попадать туда.

---

## Ограничения

Следует учитывать, что:

- IP-адрес не всегда позволяет точно определить конкретного человека;
- геолокация определяется приблизительно;
- запрос может идти через VPN, прокси или корпоративный шлюз;
- некоторые почтовые клиенты или системы защиты могут автоматически открывать ссылки, вызывая ложные срабатывания.

Поэтому уведомление следует рассматривать как **сигнал для анализа**, а не как окончательное доказательство.

---

## Краткий чек-лист

1. Создать отдельную почту для уведомлений.
2. Перейти на <https://canarytokens.org/nest/>.
3. Выбрать тип токена **Web bug**.
4. Указать email для уведомлений.
5. Вписать текст сообщения / имя токена.
6. Сгенерировать ссылку.
7. Отправить ссылку в проверяемый канал связи.
8. Ожидать уведомление до **7 дней**.
9. При срабатывании проанализировать:
   - время;
   - IP-адрес;
   - местоположение.

---

## Итог

Технология «Канарейка» позволяет организовать простую проверку канала связи на факт открытия переданной ссылки. Для этого через сервис Canarytokens создается токен типа **Web bug**, указывается email для уведомлений и описание токена, после чего формируется уникальная ссылка. Если ссылка будет открыта, на почту придет уведомление с информацией о времени, IP-адресе и примерном местоположении источника. Для стандартной проверки канала связи можно установить срок наблюдения **7 дней**.
