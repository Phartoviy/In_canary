# 🐤 Canarytokens — краткая инструкция

> Проверка канала связи на факт открытия ссылки  

---

## 📌 Что это

**Canarytokens** — сервис для создания токенов-маркеров.  
В данном сценарии используется тип **Web bug**, который позволяет:

- отследить открытие ссылки;
- получить уведомление на email;
- увидеть время события, IP-адрес и примерное местоположение.

Сайт сервиса: <https://canarytokens.org/nest/>

---

## ⚙️ Что потребуется

- отдельный email для уведомлений;
- доступ к Canarytokens;
- канал связи, который нужно проверить.

---

## 🚀 Порядок работы

### 1. Создать отдельную почту
Подготовьте отдельный email для получения уведомлений.

### 2. Открыть Canarytokens
Перейдите на:

<https://canarytokens.org/nest/>

### 3. Выбрать тип токена
Выберите:

**Web bug**

### 4. Заполнить поля
Укажите:

- **Email** для уведомлений;
- **Название токена** или текст сообщения.

**Пример имени:**
`Проверка_канала_1`

### 5. Сгенерировать ссылку
После заполнения сервис создаст уникальную ссылку.

### 6. Отправить ссылку
Направьте её в проверяемый канал связи.

### 7. Дождаться результата
Ожидайте уведомление на почту.

**Рекомендуемый срок ожидания: 7 дней**

---

## 📨 Что приходит в уведомлении

При срабатывании токена обычно доступны:

- время события;
- IP-адрес;
- примерное местоположение.

---


## ⚠️ Важно учитывать

- IP не всегда указывает на конкретного человека;
- местоположение определяется приблизительно;
- возможны VPN, прокси и корпоративные шлюзы;
- иногда бывают ложные срабатывания.

## 🏁 Итог

Canarytokens позволяет быстро проверить, был ли открыт отправленный URL.  
Для этого создаётся токен **Web bug**, ссылка отправляется в нужный канал, а результат отслеживается по email-уведомлению.
